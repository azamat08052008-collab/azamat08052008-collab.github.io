# Резюме: Азамат Назмутдинов

Сайт-резюме для заказчиков: услуги с примерными ценами из прайса 2026 и живые демо, которые можно потрогать.

| Страница | Что это |
|---|---|
| `/` | резюме: витрина услуг с демо, прайс, условия |
| `/demo/shop/` | интернет-магазин керамики «Глина»: товар «летит» в корзину, оплата понарошку |
| `/demo/bot/` | Telegram-бот барбершопа «Бритва»: запись с выбором мастера, свободное время, билет записи |
| `/demo/admin/` | админка «Бритвы»: запись из бота появляется сразу (общий localStorage), лента дня |
| `/demo/ai/` | ИИ-помощник йога-студии «Прана»: ответы заготовлены, без настоящей модели |

Лендинг и QR-меню в витрине ведут на «Подачу» (`azamat08052008-collab.github.io/podacha/`).

```bash
npm install
npm run dev
```

Фото сгенерированы Z-Image-Turbo через Hugging Face. Мастера, интерьер и студия вымышленные.
